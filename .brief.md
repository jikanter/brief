# Brief: the source of record for human intent to AI systems

## Constraints

### Hard

- A new `.brief.md` takes under sixty seconds to author.
- brief declares and emits files; it never executes. No model calls, sessions or tool loops, and no network crates (`tokio`, `reqwest`, `hyper`, `ureq`).
- Distributed as a single binary, or a single binary plus configuration files.
- Emitted files fit each target's existing conventions (`AGENTS.md`, `CLAUDE.md`, `.cursor/rules/`, aichat roles, promptfoo providers) and never replace hand-authored content.
- Installs are non-destructive, idempotent and reversible: generated content lives inside `<brief:generated>` markers or in files brief owns, and `--uninstall` removes exactly that.
- The same brief emits byte-identical output on every run: no timestamps or random values in emitted files. aichat hashes an Entity's definition into its `lock_hash`, so unstable output reads as a new version.
- The seams with the sibling repos (aichat, astrophage, llm-functions, rocky, pi) are emitted files only. A change a sibling repo needs is documented in this repo and applied in that one.
- The format extends through unknown `##` sections and new emit targets, without a grammar change.

### Soft

- Keep the format low cognitive load, not merely lower burden than prose: an author should not need `docs/brief-format.md` open to write a valid brief.
- Dogfood brief: this file is its first use case, and `brief emit claude --install` generates this repo's `CLAUDE.md` section from it.
- A new frontmatter field clears the YAGNI bar in `docs/design/frontmatter-additions.md` before it is built.

### Ask First

- Adding an emit target for a runtime brief does not support yet.
- Changing the `.brief.md` grammar or bumping `brief_version`.

## Sacred

- `docs/schema/brief-frontmatter-v1.schema.json` — generated from the Rust `Frontmatter` type; regenerate with `BLESS_SCHEMA=1 cargo test --test frontmatter_schema_tests`, never edit by hand

## Deliverable

A human-authorable format, and one CLI that checks it, compiles it, installs it reversibly and gates work against it, for every runtime that consumes intent: briefings for the coding agents (`AGENTS.md` for Codex, Cursor, Copilot and Claude Code; `CLAUDE.md` with hooks and skills; Windsurf; Aider) and definitions for the integrated stack (an aichat role, promptfoo replay against astrophage). Secondarily, the format and the target set stay extensible, so a new runtime is a new emitter rather than a new format.
